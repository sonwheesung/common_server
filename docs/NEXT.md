## 🔴 1. 웜 스타트에 하트비트가 없다 — 지표 신뢰도가 여기 걸려 있다

**사용자가 발견**: "앱에서 홈 누르고 다시 들어가는 건 접속 정보로 안 나오는 것 같다." 맞다.

하트비트는 `fetchBootstrap()`에 얹혀 있고, 그건 **JS 프로세스당 1회**만 불린다:

| 앱 | 트리거 | 재실행 조건 |
|---|---|---|
| linkmemo · idearepository | `boot-gate.tsx` → `useBootStore.fetchOnce()` | `fetched` 플래그 — 프로세스당 1회 |
| my_word | `BootstrapContext` `useEffect(…, [])` | 프로바이더 마운트 1회 |
| jogak | `app/_layout.tsx` → `useNoticeStore.load()` | `loaded` 플래그 — 프로세스당 1회 |

RN에서 홈 버튼은 프로세스를 죽이지 않는다. 포그라운드 복귀 시 루트가 다시 마운트되지 않으므로
**웜 스타트에는 하트비트가 한 번도 안 나간다.**

**결과 (셋 다 실제 왜곡)**

1. **DAU 과소집계** — 앱을 한 번 켠 뒤 안 죽이면 **다음 날부터는 아예 안 잡힌다.**
   앱을 열심히 쓰는 사용자일수록 덜 잡히는, 방향이 거꾸로인 오차다.
2. **최근 접속자(30분)** — `lastSeenAt`이 콜드 스타트 시각에 고정돼 거의 항상 0에 가깝다.
3. **시간대별 활성** — "몇 시에 쓰고 있었나"가 아니라 **"몇 시에 앱을 처음 켰나"** 의 분포다.

**할 일**

- 서버: `POST /v1/heartbeat` 신설. 세션 토큰만 받고 `recordActive()`만 한다.
  `bootstrap`을 다시 부르는 방식은 쓰지 않는다 — 페이로드가 크고 공지 읽음 상태를 흔든다.
  응답은 비워도 되고, 갱신 토큰(`session.token`)은 같이 실어도 좋다.
- SDK: `AppState` 전이 `→ 'active'`에서 호출. **앱 쪽 쿨다운 5분**(그 안이면 스킵).
  서버는 이미 멱등이라 중복은 무해하지만, 네트워크를 아끼는 건 앱의 몫이다.
- 덤: 밤 11시에 켜서 새벽 1시까지 쓰는 사용자의 **자정 넘김**도 같이 해결된다.

⚠ SDK가 또 오르므로 **`exp`(아래 2번)와 같은 판에 묶어야 한다.** 따로 내면 앱이 두 번 돈다.

## 🔴 2. `exp` 클레임 이관 — **막고 있던 세션이 없다**(2026-09-02 정정)

20:33에 이미 프로덕션에 게시됐다**(1.0.7 · 177개국). SDK `.2`와 `expo-updates`를 싣고 나갔다.
즉 **아무도 이 결정을 기다리고 있지 않았고**, 나는 반나절 지난 사실 위에 하루치 계획을 세웠다.

바뀌는 것 둘:
- **급하지 않다.** "남을 막고 있다"가 1·2번을 묶어야 할 이유였는데 그게 사라졌다. 다만 **묶는 게
  여전히 낫다** — 이유가 "앱을 두 번 돌리지 않기"로 바뀐 것뿐이다.
- 🟢 **linkmemo는 이제 OTA로 받는다.** vc11에 `expo-updates`가 들어갔으므로 `.3`은 **AAB 없이**
  나갈 수 있다(runtimeVersion `1.0.0` 유지가 조건). vc12를 굽지 않아도 된다.

상태는 `C:\project\common\PLAY_CONSOLE_STATUS.md`가 정본이다.

지금은 만료 기준이 두 곳에 복제돼 있다:

```
서버  lib/auth/session.ts   TOKEN_TTL_MS      = 180일
SDK   client/index.ts       SESSION_TTL_DAYS  = 180      ← 사본
```

값이 같아 지금은 무해하지만, 나중에 누가 서버만 바꾸면 **조용히 갈라진다.** 조각 세션이 짚었고,
"어긋나면 앱이 더 보수적인 쪽으로"라는 규율은 **사람이 지켜야 유지된다.**

**할 일**

```
signSession    → { sid, app, iat, exp: Date.now() + TOKEN_TTL_MS }
verifySession  → exp 있으면 exp 기준, 없으면 iat + TTL 폴백(기발급분 호환)
SDK tokenAlive → exp 우선, SESSION_TTL_DAYS는 레거시 폴백으로 강등
SDK_VERSION    → 2026-09-01.3  (또는 1번과 묶어 2026-09-02)
```

그러면 서버가 유일한 진실이 되고, TTL을 바꿔도 다음 갱신(최대 30일)에 자동 전파된다 — **앱 재배포 불필요.**

**TTL 숫자는 180일 그대로 둔다.** 올릴 이유였던 "이미 나간 구제 대상"이 실측으로 사라졌다
(myword는 OTA로 덮고, linkmemo vc10은 설치 0회, idearepository는 프로덕션 미출시).
`exp`가 들어가면 나중에 언제든 서버 한 줄로 바꿀 수 있으므로 지금 정할 필요가 없다.
