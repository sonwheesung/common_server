# info-scan — 바깥 정보 훑어서 **골라** 주기

> **왜 이 스킬이 있나**: 2026-09-07에 같은 정보를 **DB에 저장**하는 기능을 만들었다.
> RSS 17개에서 **721건**이 쌓였고 **0건 읽혔다.** 사용자 표현 그대로 *"너무 과한 거 같아서."*
> → 저장을 껐다. 근거는 `docs/INFO_HUB.md` §11-C에 있다:
> **"놓치면 손해"가 저장의 근거인데 커뮤니티엔 그게 없다.**
>
> 🔴 **그래서 이 스킬의 성패는 "많이 가져오기"가 아니라 "적게 남기기"에 있다.**
> 원자료 60건을 그대로 붙여넣으면 **721건 때와 똑같은 실패**다. 그럴 거면 스킬이 필요 없다.

## 1. 실행

```bash
# 기본 — 최근 5일 전 분류
node --env-file=.env.local .claude/skills/info-scan/fetch.mjs

# 분류만 (ai · devkr · idea) · 여러 번 줄 수 있다
node --env-file=.env.local .claude/skills/info-scan/fetch.mjs --category ai
node --env-file=.env.local .claude/skills/info-scan/fetch.mjs --category ai --category idea --days 7

# 키워드 (제목·요약 · 여러 개면 OR)
node --env-file=.env.local .claude/skills/info-scan/fetch.mjs --days 30 --q 이미지 --q image --q video
```

| 분류 | 무엇 | 수집원 |
|---|---|---|
| `ai` | AI 업계 소식 | OpenAI · Google DeepMind · Hugging Face · Replicate · TechCrunch AI · The Verge AI |
| `devkr` | 국내 개발 | GeekNews · 44BITS · 요즘IT · 카카오테크 · 토스테크 · 당근테크 |
| `idea` | 앱·게임 아이디어 | Show HN · Hacker News · Product Hunt · r/SideProject · r/gameideas |

⚠ **Anthropic 은 공개 RSS 가 없다**(4개 경로 전부 404, 2026-09-07 실측).
**Claude 소식은 Hacker News · TechCrunch · The Verge 로 들어온다** — `ai`·`idea` 를 함께 훑고,
필요하면 `--q Claude --q Anthropic` 로 좁힌다.

### 지원사업은 **여기서 안 가져온다**

지원사업은 **저장하는 쪽이 맞아서** 그대로 둔 기능이다(마감이 있고 놓치면 손해가 확정적이다).
마감 임박을 함께 보고할 때는 우리 서버를 부른다:

```bash
set -a && . ./.env.local >/dev/null 2>&1 && set +a
curl -s -H "Authorization: Bearer $ADMIN_TOKEN" \
  "https://common-server.vercel.app/api/admin/info?kind=grant" | head -c 4000
```

🔴 `ADMIN_TOKEN` 값을 **출력하거나 옮겨 적지 않는다.**

### 소스를 늘리려면

`info_sources` 테이블에 행을 넣는다(`tools/seed_info.ts`). **코드 변경도 재배포도 필요 없다.**
수집이 꺼져 있어도(`enabled=false`) 이 스킬은 그 목록을 쓴다 — 저장은 안 하지만 **어디를 볼지**는 거기 있다.

## 2. 🔴 보고 규칙 — 이 절이 스킬의 본체다

### 2-1. 원자료를 그대로 붙여넣지 않는다

스크립트가 60~200건을 뱉는다. **그걸 목록으로 옮기면 이 스킬은 실패한 것이다.**
사용자가 저장 방식을 끈 이유가 정확히 그 형태였다.

```
✅ 주제 3~6덩어리 · 각 덩어리 2~4줄
🚫 날짜별 60줄 나열
```

### 2-2. 각 항목에 **"그래서 나한테 뭔데"** 를 붙인다

제목만 옮기면 사용자가 다시 판단해야 한다 — 그건 아무것도 안 줄여준 것이다.
사용자의 실제 맥락에 걸어서 말한다:

| 맥락 | 어디에 쓰나 |
|---|---|
| **1인 개발자**(직원 0 · 최소 2029년까지 채용 없음) | "팀이 있어야 되는 것"은 걸러낸다 |
| 앱 4종 출시 중 — **게임**(배구명가·Delvewarden) · 일기 · 메모 · 아이디어 | 접점 있는 소식을 앞에 둔다 |
| **모바일 게임 SW 개발·공급업** · 개인사업자 | BGM·에셋·생성AI 활용은 직접 걸린다 |
| **비용 민감**(Supabase 무료 · Vercel) | 싸고 빠른 모델(Flash 계열 등) 소식은 값지다 |
| **2026-11 울산 → 경주 이전** · 창업 3년 이내(~2029-07) | 지원사업 자격에 직결 |

⚠ 이 맥락의 정본은 `C:\project\common\BUSINESS_INFO.md` §1·§1.4다. **커밋 금지 파일**이고,
값을 대화로 옮길 때는 필요한 것만 쓴다(생년월일·주소·사업자번호를 보고에 넣지 않는다).

### 2-3. 🔴 없는 걸 지어내지 않는다

그 주에 조용하면 **"조용하다"고 말한다.** 억지로 다섯 덩어리를 채우지 않는다.

```
✅ "이미지·동영상 생성은 이번 주 조용합니다 — Hugging Face·Replicate 가 그쪽이 제일 빠른데
    이번 5일은 텍스트 모델 글 위주였습니다."
🚫 관련 없는 기사를 이미지 생성 항목으로 끼워 넣기
```

⚠ **제목만 보고 내용을 단정하지 않는다.** 확신이 필요한 항목은 링크를 열어 확인하고,
안 열었으면 *"제목 기준"* 이라고 적는다. (이 저장소가 2026-09-07 하루에 세 번 밟은 함정이
전부 "값은 맞고 그 위에 얹은 해석이 사실을 넘은" 형태였다.)

### 2-4. 못 읽은 수집원을 **반드시 함께 말한다**

스크립트가 `⚠ 못 읽은 수집원` 줄을 찍는다. 그게 있으면 보고에 옮긴다.

🔴 **안 적으면 "그 소식이 없었다"와 "그 소스를 못 봤다"가 같은 화면이 된다** —
`CLAUDE.md` 의 *"알림이 0건일 때 무엇을 봤는지를 말한다"* 규약과 같은 계열이다.
⚠ Reddit 은 짧은 간격으로 연달아 부르면 **429**를 준다. 그건 고장이 아니라 잠깐 막힌 것이다.

### 2-5. 링크는 원문 그대로

스크립트가 준 URL만 쓴다. **주소를 지어내거나 기억으로 쓰지 않는다.**

## 4. 하지 않는 것

| 🚫 | 왜 |
|---|---|
| 가져온 것을 **DB에 저장** | 그래서 껐다(§11-C). 저장이 필요해지면 스킬이 아니라 그 기능을 다시 켜는 결정이다 |
| 파서를 새로 작성 | `lib/info.ts` 것을 쓴다 — 가드가 검증하는 코드다. 두 벌이면 두 곳이 다르게 읽는다 |
| 피드 목록을 이 스킬에 하드코딩 | `info_sources` 가 정본이다. 늘리는 데 코드 변경이 없어야 한다 |
| 원문 기사 **전문 복사** | 링크로 보낸다. 저작권 문제이고 값도 없다 |
| 시크릿 출력 | `ADMIN_TOKEN` · `DATA_GO_KR_SERVICE_KEY` 를 대화·로그에 남기지 않는다 |
